# Expenzo Frontend — Environment Variables

Configuration for the Vue 3 frontend (Vite).

---

## 🚀 How to Use

### 1. Copy the template

```bash
cp Expenzo-Frontend/.env.example Expenzo-Frontend/.env
```

### 2. Fill in values

### 3. Confirm gitignore

```bash
git check-ignore -v Expenzo-Frontend/.env
```

### 4. Restart Vite

```bash
npm run dev
```

---

## 📋 Variables

| Variable | Example | Required | Notes |
|---|---|---|---|
| `VITE_API_BASE_URL` | `http://localhost:8080` | ✅ | Backend URL |

```properties
VITE_API_BASE_URL=http://localhost:8080
```

---

## ⚠️ Important — Only Public Values

Vite **inlines env vars into the shipped JavaScript bundle at build time**.
Only variables prefixed with `VITE_` are exposed. And every value you put
here **becomes public** when the app is deployed.

**Never** put secrets (API keys, database passwords, JWT secrets) in this file.
Frontend env vars are for URLs, feature flags, and public IDs only.

---

## 🌐 Production URL

When you deploy the frontend, set:

```properties
VITE_API_BASE_URL=https://api.expenzo.com
```

And rebuild:

```bash
npm run build
```

The built bundle will call the production backend URL.

---

## 🎯 After Changing

Vite HMR does **not** reload env vars on the fly. **Restart the dev server:**

```bash
# Stop the current process (Ctrl+C)
npm run dev
```
