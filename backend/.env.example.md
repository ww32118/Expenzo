# Expenzo Backend — Environment Variables Template

This file documents every environment variable / property the Expenzo backend
needs to run. Copy the values into `application-local.properties` (which is
gitignored) and fill in real values.

---

## 🚀 How to Use

### 1. Copy the template to the real config location

```bash
cp Expenzo/.env.example Expenzo/src/main/resources/application-local.properties
```

Or if you're using this Markdown file as reference, manually create
`Expenzo/src/main/resources/application-local.properties` with the keys below.

### 2. Fill in real values

Every placeholder below must be replaced with a real value.

### 3. Confirm it's gitignored

```bash
git check-ignore -v Expenzo/src/main/resources/application-local.properties
```

Should output something like:
```
.gitignore:8:application-local.properties    Expenzo/src/main/resources/application-local.properties
```

### 4. Activate the profile

`application.properties` already contains:

```properties
spring.profiles.active=local
```

This tells Spring Boot to load `application-local.properties` on top of
`application.properties`. **No extra config needed.**

## 📋 Variables Reference

### 1. Database (MySQL 8)

The `expenzo` database and all tables are auto-created by Hibernate on
first startup (`spring.jpa.hibernate.ddl-auto=update`).

If you prefer to create the DB manually first:

```sql
CREATE DATABASE expenzo CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

| Property | Example | Required |
|---|---|---|
| `spring.datasource.username` | `root` | ✅ |
| `spring.datasource.password` | `your_mysql_password_here` | ✅ |

```properties
spring.datasource.username=root
spring.datasource.password=your_mysql_password_here
```

> **Note:** The datasource URL, driver, and DDL settings live in
> `application.properties` — only credentials go here.

### 2. JWT (JSON Web Token)

Used to sign and verify JWTs issued after login. Algorithm: **HS256**.

| Property | Example | Required |
|---|---|---|
| `jwt.secret` | `<base64-encoded 64-byte random>` | ✅ |

```properties
jwt.secret=REPLACE_WITH_BASE64_ENCODED_SECRET_AT_LEAST_32_BYTES
```

#### Requirements

- Must be **BASE64-encoded**
- Must decode to **at least 32 bytes (256 bits)** — HS256 requirement
- Must be **cryptographically random** — not a human-readable string
- Never share it; never commit it

#### How to generate

**OpenSSL:**
```bash
openssl rand -base64 64
```

**Node.js:**
```bash
node -e "console.log(require('crypto').randomBytes(64).toString('base64'))"
```

**PowerShell:**
```powershell
[Convert]::ToBase64String(
  [System.Security.Cryptography.RandomNumberGenerator]::GetBytes(64)
)
```

**Python:**
```bash
python -c "import secrets, base64; print(base64.b64encode(secrets.token_bytes(64)).decode())"
```

> **Token expiry:** Set in `application.properties` as
> `jwt.expiration=604800000` (7 days). Change there if needed — not here.

### 3. Google OAuth2

Enables the **"Continue with Google"** login flow.

| Property | Example | Required |
|---|---|---|
| `spring.security.oauth2.client.registration.google.client-id` | `xxx.apps.googleusercontent.com` | ✅ |
| `spring.security.oauth2.client.registration.google.client-secret` | `GOCSPX-...` | ✅ |

```properties
spring.security.oauth2.client.registration.google.client-id=YOUR_CLIENT_ID.apps.googleusercontent.com
spring.security.oauth2.client.registration.google.client-secret=GOCSPX-YOUR_CLIENT_SECRET
```

#### Setup steps

1. Go to [Google Cloud Console → Credentials](https://console.cloud.google.com/apis/credentials)
2. Select (or create) a project
3. Click **Create Credentials → OAuth client ID**
4. Application type: **Web application**
5. Under **Authorized JavaScript origins**, add:
   ```
   http://localhost:5173
   http://localhost:8080
   ```
6. Under **Authorized redirect URIs**, add:
   ```
   http://localhost:8080/login/oauth2/code/google
   ```
7. Copy the **Client ID** and **Client Secret** into the properties above

#### Production note

When you deploy, add your production domain to both lists:

```
Authorized JavaScript origins:
  https://expenzo.com

Authorized redirect URIs:
  https://api.expenzo.com/login/oauth2/code/google
```

> **Scope and provider URIs** are already configured in
> `application.properties` — you don't need to set them here.

### 4. Gmail SMTP

Used to send all transactional emails: OTP codes, password reset links,
welcome messages with temp passwords, budget alerts.

| Property | Example | Required |
|---|---|---|
| `spring.mail.username` | `you@gmail.com` | ✅ |
| `spring.mail.password` | `abcdefghijklmnop` (16 chars) | ✅ |

```properties
spring.mail.username=your_email@gmail.com
spring.mail.password=your_16_char_app_password
```

#### Why an App Password (not your normal Gmail password)

Google blocks logins from apps that don't support modern authentication.
An **App Password** is a 16-character token that works specifically for
SMTP from authorized apps.

#### Setup steps

1. Enable 2-Step Verification: https://myaccount.google.com/security
2. Go to App Passwords: https://myaccount.google.com/apppasswords
3. App: **Mail** | Device: **Other (Custom name)** → name it **"Expenzo Dev"**
4. Google generates a code like `abcd efgh ijkl mnop`
5. Copy it and **remove all spaces** → `abcdefghijklmnop`
6. Paste into `spring.mail.password` above

#### The from address

Emails are sent **from** this Gmail address. The display name is set to
`"Expenzo"` in `EmailService.java`:

```java
helper.setFrom(fromEmail, "Expenzo");
```

#### Deliverability warning

> **Gmail-to-Gmail SMTP emails often land in Spam.** For production,
> switch to a transactional provider such as **Resend**, **SendGrid**,
> or **Amazon SES**. See the *Deployment Notes* section in `README.md`.

> **All other mail settings** (host, port, TLS, timeouts) are already set
> in `application.properties` — you don't need to duplicate them here.

### 5. Optional Overrides (Local Dev Only)

These normally live in `application.properties` with sensible defaults.
Override here only if needed.

```properties
# Frontend URL — used in email links and OAuth2 redirect target
# app.frontend.url=http://localhost:5173

# Show SQL in console while debugging
# spring.jpa.show-sql=true

# Pretty-print SQL output
# spring.jpa.properties.hibernate.format_sql=true

# Verbose security logging (very noisy — for debugging only)
# logging.level.org.springframework.security=TRACE
```

## 🚫 What's *Not* Here

These are already in `application.properties` and contain **no secrets** —
safe to commit:

| Setting | Value |
|---|---|
| `spring.datasource.url` | `jdbc:mysql://localhost:3306/expenzo` |
| `spring.datasource.driver-class-name` | `com.mysql.cj.jdbc.Driver` |
| `spring.jpa.hibernate.ddl-auto` | `update` (dev) |
| `jwt.expiration` | `604800000` (7 days) |
| `app.frontend.url` | `http://localhost:5173` |
| `spring.mail.host` | `smtp.gmail.com` |
| `spring.mail.port` | `587` |
| `spring.security.oauth2.client.registration.google.scope` | `openid,profile,email` |
| `spring.security.oauth2.client.provider.google.*` | Google's OIDC endpoints |

**Rule of thumb:** anything that changes per developer or per environment
goes in `application-local.properties`. Everything else stays in
`application.properties`.

## ✅ Verify Your Setup

After filling in `application-local.properties`, restart Spring Boot and
check the console:

```
The following 1 profile is active: "local"
HikariPool-1 - Added connection ...
Started ExpenzoApplication in X seconds
```

If you see that, all secrets loaded correctly.

Test each flow:

- **Local signup** → OTP email → verify → login
- **Forgot password** → reset email → click link → set password → login
- **Google login** → dashboard

If all three work, your environment is fully configured. ✅
